# VYRO

ספריית סרטים וסדרות אישית ל-Android ול-Android TV.
A personal movie & series library for Android and Android TV.

## הורדה · Download

**[⬇ להורדת הגרסה האחרונה של VYRO (APK)](https://github.com/yanirkhr/vyro/releases/latest/download/VYRO.apk)**

כל הגרסאות: [Releases](https://github.com/yanirkhr/vyro/releases)

## התקנה · Install

1. מורידים את הקובץ `VYRO.apk` לטלפון או לטלוויזיה.
2. פותחים אותו ומאשרים "התקנה ממקור זה".
3. מגרסה 1.4 והלאה האפליקציה בודקת עדכונים בעצמה ושולחת התראה כשיוצאת גרסה חדשה.

## מה יש באפליקציה

- תיקיות נפרדות לסרטים ולסדרות, עם תמונת נושא ותיאור
- עמוד לכל סרט עם תמונת רקע, שנה, תיאור וכתוביות
- ניגון ב-VLC, כתוביות בעברית מוצגות אוטומטית
- סנכרון בין הטלפון לטלוויזיה ברשת ה-Wi-Fi הביתית, כולל ניגון סרט שנמצא במכשיר השני
- ממשק בעברית או באנגלית, מותאם לטלפון ולשלט של Android TV
